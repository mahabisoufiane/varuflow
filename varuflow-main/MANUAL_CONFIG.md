# MANUAL_CONFIG.md — External credentials that require human action

This file lists every credential, secret, or external resource that cannot
be generated by code and must be obtained from an external provider, then
added to Railway (or your `.env` file for local dev).

---

## Redis (C-1 — multi-replica rate limiting)

**Variable:** `REDIS_URL`  
**Required for:** Shared rate-limiter state across multiple Railway replicas.  
**Optional:** Yes — omit to fall back to the in-memory counter (single-replica only).

**How to obtain:**
1. In Railway: open your project → **+ New** → **Database** → **Redis**.
2. Railway provisions a Redis instance and exposes `REDIS_URL` in the
   service's **Variables** tab.
3. Copy that URL to your backend service's Variables as `REDIS_URL`.

**Format:** `redis://[:password@]host:port[/db]`  
**TLS:** Use `rediss://` (double-s) for TLS connections (Railway default).

---

## PostgreSQL (DATABASE_URL)

**Variable:** `DATABASE_URL`  
**Required for:** All backend data operations.  
**Format (asyncpg):** `postgresql+asyncpg://USER:PASSWORD@HOST:5432/DBNAME`

Railway provides a `DATABASE_URL` in `postgres://` format — prepend
`+asyncpg` and change the scheme:

```
postgres://USER:PASS@HOST:5432/DB
→ postgresql+asyncpg://USER:PASS@HOST:5432/DB
```

## Supabase

**Variables:** `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `SUPABASE_JWT_SECRET`  
**Source:** Supabase project settings → API.

- `SUPABASE_URL`: Project URL (e.g. `https://xyzabcde.supabase.co`)
- `SUPABASE_SERVICE_KEY`: Service role key (secret — never expose to browser)
- `SUPABASE_JWT_SECRET`: JWT secret (Settings → API → JWT Settings)

## Stripe

**Variables:** `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`,
`STRIPE_PRO_PRICE_ID`, `STRIPE_STARTER_PRICE_ID`,
`STRIPE_STOREFRONT_WEBHOOK_SECRET`  
**Source:** Stripe Dashboard → Developers.

- **Secret key:** Developers → API keys → Secret key
- **Webhook secrets:** Developers → Webhooks → each endpoint's signing secret
- **Price IDs:** Products → your plan products → price ID

---

## Fortnox OAuth

**Variables:** `FORTNOX_CLIENT_ID`, `FORTNOX_CLIENT_SECRET`,
`FORTNOX_REDIRECT_URI`, `FORTNOX_ENCRYPTION_KEY`

- Client ID / secret: from the Fortnox developer portal app registration.
- Redirect URI: `https://<your-railway-host>/api/integrations/fortnox/callback`
- Encryption key: `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`

---

## PII Encryption

**Variable:** `PII_ENCRYPTION_KEY`  
**Generate:** `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`  
**Required in production.** Startup refuses to boot without it.
